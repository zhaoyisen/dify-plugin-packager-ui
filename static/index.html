Packaging Control Room

把插件离线包重打包流程，压缩进一块可直接操作的工作甲板。

面向 Linux / Kubernetes 部署场景的单页控制台。保留现有 dify-plugin-repackaging-plus 脚本能力，只把最常用的输入、状态追踪和产物下载整理成更清楚的操作路径。

Operation Brief
3 种来源入口

本地上传、GitHub Release、Marketplace 三条接入链路统一到同一套任务通道。

Compatibility
等待环境探测

依据当前主机架构自动判断脚本路径，避免选择不支持的目标组合。

Delivery
实时日志 + 直接下载

脚本输出流、最近任务和最终离线包会在同一视野里连续更新。
